# Time Tracker

A personal time tracker for charge-number-based work, built in two halves:

- **Capture** (this repo): a home-screen web app for iPhone and any browser. It logs time against **nicknames only**.
- **Ledger** (built on the work laptop): maps nicknames to real projects and charge numbers, imports the emailed entries, and produces daily and weekly totals in tenths of an hour.
